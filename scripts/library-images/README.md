# Тимчасові картинки з бібліотек

Поки немає ключа для генерації ілюстрацій через ШІ, картинки сайту зібрано з
3D-іконок **Microsoft Fluent Emoji** (MIT) і шрифту **Nunito** (SIL OFL).
Джерела й ліцензії показано на сторінці `/litsenzii`.

- `mapping.py` — яка іконка стоїть у якому місці (теми, вік, подарунки тощо).
- `generate.py` — збирає WebP у `public/img/...` (іконки тем, великі сцени, обкладинки з іменами,
  зразки стилів, картинки статей).
- `write_list.py` — записує `src/lib/library-images.json`, щоб сторінка `/zaglushky`
  показувала, які картинки ще тимчасові.

Опис для генерації справжньої ілюстрації через ШІ є в кожного місця в `src/lib/images.ts`
(поле `prompt`) і на сторінці `/zaglushky`. Згенеруйте картинку, збережіть як WebP під тим самим
іменем — і вона замінить бібліотечну.

Щоб перезібрати: потрібні Python 3 з Pillow; `generate.py` сам завантажує потрібні PNG
з репозиторію Fluent Emoji, а `data.json` (імена, статті, приклади) вивантажується з коду сайту.
