# Описи для генерації ілюстрацій через ШІ

`prompts.json` — усі місця під картинки сайту з описами (id, файл, розмір, опис англійською),
вивантажені з `src/lib/images.ts`. Ті самі описи з кнопкою «Копіювати» є на сторінці `/zaglushky`.

Згенеровану картинку збережіть як WebP під іменем із поля `file` у папку `public/` —
вона замінить тимчасову бібліотечну (див. `scripts/library-images`).

Локальна генерація через ComfyUI + FLUX.1 schnell (вересень 2026) дала слабкий результат
(криві руки, вигадані написи на книжках), тому від неї відмовились.
